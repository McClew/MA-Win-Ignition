MALWARE ANALYSIS LAB ENVIRONMENT - INSTALLED TOOLS REFERENCE

-------------------------------------------------------------------------------
STATIC ANALYSIS
-------------------------------------------------------------------------------
[+] bindiff
    - Use Case: A binary diffing engine used to compare two disassembled files (usually via IDA Pro) to identify code reuse, patches, or malware variants.
    - How to Access: Launch via the shortcut in the 'MalwareTools' desktop folder.

[+] capa
    - Use Case: Automatically detects capabilities in executable files (e.g., "checks for debugger", "installs service") using YAML-defined signatures.
    - How to Access: Launch via the shortcut in the 'MalwareTools' desktop folder.

[+] die (Detect It Easy)
    - Use Case: Advanced PE packer, compiler, and linker identifier. Vital for checking entropy to see if a sample is packed or encrypted.
    - How to Access: Launch via the shortcut in the 'MalwareTools' desktop folder.

[+] flare-floss
    - Use Case: Automatically extracts static, stacked, and dynamically obfuscated/encoded strings from binaries that standard 'strings' tools miss.
    - How to Access: Launch via the shortcut in the 'MalwareTools' desktop folder.

[+] ghidra
    - Use Case: NSA's open-source software reverse engineering suite. Provides a powerful disassembler and decompiler for deeper binary inspection.
    - How to Access: Launch via the shortcut in the 'MalwareTools' desktop folder.

[+] ida-free
    - Use Case: The industry-standard disassembler. Used to parse binary machine code into assembly and map data references.
    - How to Access: Launch via the shortcut in the 'MalwareTools' desktop folder.

[+] pe-bear
    - Use Case: Visual PE file structure viewer. Excellent for fixing malformed headers or reconstructing imported address tables (IAT) from memory dumps.
    - How to Access: Launch via the shortcut in the 'MalwareTools' desktop folder.

[+] pestudio
    - Use Case: Initial triage tool for malicious Windows executables. Spotlights blacklisted imports, suspicious strings, and structural anomalies instantly.
    - How to Access: Launch via the shortcut in the 'MalwareTools' desktop folder.

[+] resourcehacker
    - Use Case: Explores and extracts built-in file resources (icons, manifest XML files, configurations, embedded malicious payloads/dropped files).
    - How to Access: Launch via the shortcut in the 'MalwareTools' desktop folder.


-------------------------------------------------------------------------------
DYNAMIC ANALYSIS & SYSTEM MONITORING
-------------------------------------------------------------------------------
[+] fakenet-ng
    - Use Case: Intercepts and logs all network traffic generated by malware while tricking the sample into thinking it has a real internet connection.
    - How to Access: Launch via the shortcut in the 'MalwareTools' desktop folder.

[+] processhacker
    - Use Case: Robust process monitoring tool to watch malicious processes spawn, inspect active handles, pull strings from memory, or dump active payloads.
    - How to Access: Launch via the shortcut in the 'MalwareTools' desktop folder.

[+] regshot
    - Use Case: Takes "before and after" registry snapshots during dynamic execution to precisely track system modifications made by a malware sample.
    - How to Access: Launch via the shortcut in the 'MalwareTools' desktop folder.

[+] sysinternals (Suite Folder)
    - Use Case: A collection of vital system-level analysis utilities including Process Monitor (ProcMon) and Autoruns for behavior tracing.
    - How to Access: Launch via the shortcut folder in the 'MalwareTools' desktop folder.

[+] systeminformer
    - Use Case: The modernized successor to Process Hacker. Used for deep system, driver, network connections, and security object auditing.
    - How to Access: Launch via the shortcut in the 'MalwareTools' desktop folder.

[+] wireshark
    - Use Case: Captures and deep-dives into raw PCAP network packets to analyze real-time communications, commands, and active C2 protocols.
    - How to Access: Launch via the shortcut in the 'MalwareTools' desktop folder.

[+] x64dbg
    - Use Case: Open-source x64/x86 assembly debugger. Essential for bypassing anti-analysis tricks, analyzing code execution streams, and taking control of binary memory.
    - How to Access: Launch via the shortcut in the 'MalwareTools' desktop folder.


-------------------------------------------------------------------------------
MALICIOUS DOCUMENT & FILE ANALYSIS
-------------------------------------------------------------------------------
[+] oletools
    - Use Case: Essential toolkit for auditing, parsing, and tearing apart malicious Microsoft Office documents, RTF files, and macro components.
    - How to Access: CLI tool. Open a PowerShell/CMD window anywhere and call its individual modules directly:
                     - `oleid <file>`     (Triage files for VBA macros/exploits)
                     - `olevba <file>`   (Extract and analyze VBA macro code)
                     - `macro_raptor`    (Detect suspicious macro designs)
                     - `mraptor <file>`  (Automated structural vetting rules)
                     - `rtfobj <file>`   (Extract embedded objects inside RTF files)

[+] pcodedmp
    - Use Case: Disassembles and dumps raw VBA p-code directly out of macro documents. Essential for bypassing "VBA stomping," where threat actors delete source code to blind typical macro parsers.
    - How to Access: CLI tool. Open a PowerShell/CMD window anywhere and type: `pcodedmp <file>`

[+] pdfid
    - Use Case: Scans PDF files to check for risky elements like /JavaScript, /OpenAction, /AA, or /Launch that indicate exploit conditions.
    - How to Access: CLI tool. Open a PowerShell/CMD window anywhere and type: `pdfid <file>`

[+] pdf-parser
    - Use Case: Extracts specific structural elements (objects, streams, dictionaries) from suspect PDFs to pull out concealed shellcode or URLs.
    - How to Access: CLI tool. Open a PowerShell/CMD window anywhere and type: `pdf-parser <file>`
